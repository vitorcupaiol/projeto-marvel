# projeto-marvel
Projeto: Pipeline de Dados de Filmes Marvel com Delta Lake
Objetivo
Construir um pipeline de dados simples com Databricks que:

Ingesta arquivos de filmes da Marvel (CSV)

Armazena em camadas Bronze, Silver e Gold (arquitetura Lakehouse)

Aplica transformações e análises com PySpark

Usa Delta Lake para versionamento e otimização
